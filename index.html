DOCUMENTATION

InterActiveTooltipPopover Plugin

Author: fungus007

Overview

InterActiveTooltipPopover is a modern, highly customizable jQuery tooltip & popover plugin. It supports 13+ unique styles, advanced animations, smart positioning, accessibility, and theming. Easily integrate with any project using simple data attributes or the jQuery API.

Quick Start

  1. Include jQuery, InterActiveTooltipPopover.js, and InterActiveTooltipPopover.css in your page.
  2. Add data-tooltip and data-tooltip-style to any element.
  3. Optionally use data-tooltip-direction, data-tooltip-theme, etc. for more control.
  4. Initialize via jQuery if needed:
    $('.your-selector').InterActiveTooltipPopover(options);

Key Features

  • 13+ unique tooltip styles & animations
  • Sticky, interactive, and HTML content support
  • Customizable arrows, smart auto-flip, mouse-follow
  • Keyboard navigation & ARIA accessibility
  • Custom themes, branding, and dark mode
  • jQuery API and data-attribute configuration
